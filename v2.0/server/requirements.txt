# Pinned with == rather than >= for reproducible installs (both in CI and
# production). Unpinned ">=" lets a fresh install silently pull in an
# untested newer release. To upgrade a dependency: bump its pin here,
# re-check resolution (`pip install --dry-run -r server/requirements.txt`
# on Python 3.11), run `pip-audit --no-deps --disable-pip -r
# server/requirements.txt`, run the full test suite (see v2.0/tests/) plus
# a manual smoke test of the affected subsystem, then commit the bump on its
# own.
#
# 2026-10 security refresh (Dependabot pip alerts): torch, Pillow, onnx,
# scikit-learn, pytest, python-dotenv and the transitive starlette were moved
# to patched releases. The old set was not resolvable at all (boxmot 10.x pins
# numpy==1.23.1/1.26.4 and torchvision<0.18, which caps torch at a vulnerable
# 2.2.x), so the whole stack moved to numpy 2.x: boxmot 16, ultralytics 8.4,
# mediapipe 0.10.31 (Tasks API only, no numpy<2 cap), opencv 4.13,
# onnxruntime 1.24, shapely 2.1. Resolution verified for CPython 3.11 on
# manylinux x86_64 (CI) and macOS arm64. Before relying on it, smoke-test the
# heavy stack (YOLO load/inference, FaceLandmarker, ByteTrack, ONNX classifier)
# on a real machine.

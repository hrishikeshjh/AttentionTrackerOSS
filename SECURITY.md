## Reporting a Vulnerability

We take the security of AttentionTrackerOSS and its biometric and edge data handling seriously.

If you discover a security vulnerability, please **DO NOT open a public issue**. Instead, report it responsibly via:

- **Email**: `hrishikeshjhapersonal@gmail.com`
- **GitHub Security Advisory**: [Create Private Advisory](https://github.com/hrishikeshjh/AttentionTrackerOSS/security/advisories/new)

Please include:
1. Description of the vulnerability.
2. Steps or proof-of-concept to reproduce the issue.
3. Potential impact on biometric privacy, server authentication, or hardware actuation.
4. Proposed remediation (if available).

We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure timeline.
